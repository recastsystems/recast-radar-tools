# recast-radar-tools

Pure-Rust weather radar tools: decoding (NEXRAD Level II and III, ODIM_H5,
CfRadial, DORADE, JMA), data access, dealiasing and QC, derived products,
gridding, tracking, and headless rendering.

Design: [docs/superpowers/specs/2026-09-16-recast-radar-tools-design.md](docs/superpowers/specs/2026-09-16-recast-radar-tools-design.md)
